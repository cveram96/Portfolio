Median House Value Prediction in California

Analysis with Multiple Linear Regression

  • Dataset: fetch_california_housing (20,640 records)
  • Key variables: Median income, housing age, location
  • R²: 0.6364 | RMSE: 0.6574
  • Technologies: Python, scikit-learn, pandas, matplotlib

Project Context

Analysis of the California housing market using 1990 census data to predict median house value across districts.

Main variables:

  • MedInc: Median household income
  • HouseAge: Median house age
  • AveRooms: Average rooms
  • AveBedrms: Average bedrooms
  • Population: Population in the block
  • AveOccup: Average occupancy
  • Latitude: Geographic latitude
  • Longitude: Geographic longitude

Detailed Methodology

1. Exploratory Data Analysis (EDA)

  • Variable distributions and outlier detection
  • Correlation matrix between features
  • Visualization of geographic patterns

2. Preprocessing

  • Feature engineering:
    • Rooms_per_Population: Rooms per person
    • Bedroom_Ratio: Bedroom ratio
    • People_per_House: Occupants per house
  • Outlier removal using the IQR method
  • Standardization of numeric variables

3. Modeling

  • Pipeline components:
    • StandardScaler for normalization
    • PolynomialFeatures for non-linear relationships
    • SelectKBest for feature selection
    • LinearRegression as final model
  • Optimization with RandomizedSearchCV

Geographic Price Distribution in California

Geospatial visualization of 20,640 census block groups mapping median home values across California. Distinct high-density clusters are evident along coastal metropolitan areas (San Francisco Bay Area, Los Angeles, San Diego) compared to lower-cost agricultural zones in the Central Valley.

Assumption Validation

  • Residual normality: Not satisfied (p < 0.05)
  • Homoscedasticity: Not satisfied (p < 0.05)
  • Independence: Satisfied (Durbin-Watson ≈ 2)

Econometric Residual Diagnostics Suite

Four-panel diagnostic analysis validating linear regression Gauss-Markov assumptions: Residuals vs Fitted (non-constant variance), Normal Q-Q plot (heavy tails rejecting normality with Shapiro-Wilk p < 0.001), Scale-Location (heteroscedasticity confirmed by Breusch-Pagan p < 0.001), and Residual Density confirming zero autocorrelation (Durbin-Watson ≈ 2.0).

Conclusions and Recommendations

Key Findings

  • Median income is the strongest predictor of house value
  • Geographic location shows clear spatial patterns
  • More occupied houses tend to be worth less
  • Engineered features improved predictive power

Limitations

  • The model does not satisfy residual normality
  • Presence of heteroscedasticity
  • Complex relationships not captured by linear regression

Recommendations

  • Try non-linear models (Random Forest, XGBoost)
  • Apply transformations to improve normality
  • Consider spatial models for location
  • Explore techniques to handle heteroscedasticity
