Customer Churn Prediction

Comparison between Random Forest and Multilayer Perceptron

  • Dataset: WA_Fn-UseC_-Telco-Customer-Churn (7,043 records)
  • Key variables: tenure, Contract, MonthlyCharges, InternetService
  • Best F1-Score: 0.634 (MLP with RandomUnderSampler)
  • Technologies: Python, scikit-learn, pandas, matplotlib, imblearn

Project Context

Analysis of service cancellation (churn) in telecommunications to identify customers with high probability of leaving and enable preventive retention strategies.

Main Variables:

  • tenure: Number of months as a customer
  • Contract: Contract type (Month-to-month, 1 year, 2 years)
  • MonthlyCharges: Monthly charges
  • TotalCharges: Total accumulated charges
  • InternetService: Type of internet service
  • OnlineSecurity: Has online security
  • TechSupport: Has technical support
  • PaymentMethod: Payment method

Detailed Methodology

1. Exploratory Data Analysis (EDA)

  • Imbalanced class distribution (73.5% No Churn vs 26.5% Churn)
  • Association analysis using Cramér's V for categorical variables
  • Levene's test and Welch's t-test for numerical variables
  • Visualization of relationships between variables and Churn

2. Preprocessing

  • Data cleaning:
    • Data type conversion
    • Imputation of missing values using the median
    • Removal of unique ID column (customerID)
  • Feature transformation:
    • Standardization with StandardScaler for numeric features
    • Encoding with OneHotEncoder for categorical features
  • Balancing techniques:
    • SMOTE
    • RandomUnderSampler
    • ADASYN
    • SMOTEENN

3. Modeling

  • Random Forest:
    • Optimization with RandomizedSearchCV
    • Stratified cross-validation
    • Hyperparameters: n_estimators, max_depth, min_samples_split
  • Multi-Layer Perceptron (MLP):
    • Optimization with RandomizedSearchCV
    • Hyperparameters: hidden_layer_sizes, activation, solver

Key Findings

  • Customer tenure is the most influential factor
  • Long-term contracts significantly reduce churn
  • Fiber internet service increases churn probability
  • Payment by electronic check is associated with higher churn
  • Lack of add-on services (security, tech support) increases churn

Conclusions and Recommendations

Model Comparison

  • Random Forest (SMOTEENN) maximizes churn detection with higher recall (77.7%), capturing more customers at risk with minimal false negatives.
  • MLP (RandomUnderSampler) achieves slightly higher precision (54.2%), resulting in a lower false alarm rate with a competitive 76.3% recall.
  • SMOTEENN and RandomUnderSampler are the best balancing techniques

Limitations

  • Imbalanced dataset (26.5% positive cases)
  • Potential overfitting with oversampling techniques

Recommendations

  • Implement Random Forest with SMOTEENN for retention strategies
  • Prioritize customers with month-to-month contracts and fiber internet
  • Offer incentives to migrate to long-term contracts
  • Improve add-on services (security, tech support)
  • Explore alternative models such as XGBoost or deeper neural networks
