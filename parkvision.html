Executive Summary

ParkVision AI

End-to-End Real-Time Smart Parking Monitoring System

  • Objective: Automate parking bay occupancy monitoring using existing optical video feeds (CCTV and RTSP streams) as an alternative to installing physical pavement sensors.
  • Data: Real-time optical video feeds (networked RTSP IP cameras, USB webcams, and MP4 video files).
  • Method: End-to-end computer vision pipeline combining Ultralytics YOLOv8 vehicle detection, ByteTrack spatial tracking, vector polygon intersection (Point-in-Polygon & IoU), and a FastAPI WebSockets server with DirectML/CUDA GPU acceleration.
  • Result: Real-time slot status detection, automatic Available/Occupied state tracking, and persistent SQLite database logging for operational reports.
  • Code: GitHub Repository (Files/parking_monitor)

Project Overview & Business Impact

Urban parking management is a major operational bottleneck in smart cities and commercial hubs. Drivers spending 15–20 minutes searching for vacant spots generates traffic congestion, increases carbon emissions, and creates customer friction in commercial facilities.

ParkVision AI was designed and engineered as an end-to-end Computer Vision web application that transforms conventional video streams (CCTV, webcams, or IP cameras) into an automated intelligent occupancy monitoring system without requiring expensive ground sensors.

Key Value Drivers:

  • Hardware Agnostic: Integrates seamlessly with existing optical camera infrastructure via RTSP or USB, accelerated by DirectML (AMD/Intel) and CUDA (NVIDIA).
  • Operational Cost Reduction: Eliminates the need for physical ultrasonic/magnetic ground sensors.
  • Real-Time Auditing: Instant availability tracking with sub-second latency and visual alerts.
  • Historical Insights: Continuous persistence of occupancy timestamps to analyze peak demand and parking turnover.

System Architecture & Workflow

1. Multi-Source Video Stream Ingestion

An asynchronous capture pipeline handles video inputs (local MP4 recordings, live USB webcams, or networked RTSP CCTV cameras) in dedicated asynchronous background tasks with OpenCV and FastAPI WebSockets, ensuring the responsive web interface delivers smooth live streaming at 30 FPS.

2. Deep Learning Detection & Tracking Pipeline

  • Model: Ultralytics YOLOv8 nano/medium segmentation weights (optimized for real-time edge inference).
  • Target Classes: Multi-class vehicle detection (cars, vans, trucks, buses, motorcycles).
  • Inference Strategies: Flexible inference modes including direct YOLO bounding box detection, background subtraction, and hybrid thresholding for low-contrast lighting conditions.

3. Interactive Spatial Slot Management

The application includes an integrated polygon management tool where operators can draw, calibrate, and save individual parking bay coordinates directly over the camera feed. Each spot is stored as a vector polygon in the database.

4. Occupancy Logic & State Machine

For each frame, detected vehicle centroids and bounding polygons are computed against the calibrated parking spots using geometric intersection algorithms (Point-in-Polygon & IoU). Spaces are color-coded in real time:

  • Green Zone: Available parking slot.
  • Red Zone: Occupied slot with detected vehicle.

5. Data Persistence & Analytics Layer

Every occupancy change triggers an event logged to a local SQLite database (parking.db) and continuous CSV logs, recording spot IDs, status timestamps, and session durations for downstream business analytics.

Docker Production

Docker Containerization & Edge Deployment

ParkVision is fully containerized with Docker and Docker Compose, supporting automated GPU passthrough for NVIDIA CUDA and host DirectML acceleration for Intel/AMD chips: 

# Build & launch headless inference server with WebSocket streaming

docker-compose -f docker/docker-compose.yml up --build -d
# Run DirectML accelerated inference against networked RTSP CCTV stream

python app/main.py --source "rtsp://admin:pass@192.168.1.100:554/stream1" --device directml --conf 0.45
