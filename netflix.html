Key Business Findings & Strategic Insights

1. Format Distribution vs. Engagement Paradox

While feature films constitute the majority of unique catalog titles (~70%), television series generate significantly higher average votes and viewer engagement per title (VPT). This quantitative disparity highlights that episodic content drives sustained subscriber retention, recurring platform visits, and higher customer lifetime value (LTV).

2. Quality & Rating Spread (Bell-Shaped Clustering)

The IMDb audience rating distribution exhibits a normal bell-shaped curve with over 65% of all titles concentrated in the 6.0–7.5 score band. High-tier critically acclaimed productions (ratings >= 8.0) represent a scarce premium segment (<8% of catalog) that serves primarily as a subscriber acquisition and brand prestige driver, while mid-tier titles provide everyday viewing volume.

3. International Expansion & Regional Production Hubs

Geographic mapping reveals the United States as the historical core contributor, but highlights aggressive content diversification across emerging international hubs: India (high-volume Bollywood releases), United Kingdom, South Korea (K-drama surge), and Japan (Anime). This illustrates Netflix's strategic pivot toward 'local-for-local' content that simultaneously achieves cross-border viral appeal.

4. Catalog Modernity & Originals Pivot

Temporal release trends show a steep exponential concentration of titles released after 2015. This reflects Netflix's structural shift away from licensing costly legacy third-party studio catalogs toward producing proprietary 'Netflix Originals', insulating the business from studio content clawbacks and intellectual property exclusivity wars.

DAX Modeling & Engineering Architecture

Production DAX measures implemented in the tabular semantic model (Calculations table):

Catalog Volume & Basic Aggregations

Core scalar aggregations computing distinct titles, total audience votes, and average ratings across active filter contexts.

// Core Catalog Aggregations
# Titles = DISTINCTCOUNT(netflix_list[ID])

Avg Rating = AVERAGE(netflix_list[Rating])

# Votes = SUM(netflix_list[Votes])

# Votes Per Title = DIVIDE([# Votes], [# Titles])

Context-Filtered Segmentations (Movies vs. Television)

Measures leveraging CALCULATE and FILTER to evaluate performance metrics independently across Movies and Television series.

// Format-Specific Context Segmentation
Movie Titles = 
CALCULATE(
    'Calculations'[# Titles], 
    FILTER(netflix_list, netflix_list[Listing Types] = "Movie")
)

TV Titles = 
CALCULATE(
    'Calculations'[# Titles], 
    FILTER(netflix_list, netflix_list[Listing Types] = "Television")
)

Movie Avg Rating = 
CALCULATE(
    [Avg Rating], 
    FILTER(netflix_list, netflix_list[Listing Types] = "Movie")
)

TV Avg Rating = 
CALCULATE(
    [Avg Rating], 
    FILTER(netflix_list, netflix_list[Listing Types] = "Television")
)

Dynamic KPI Labeling & Engagement Ratios

Composite string measures computing percentage of total votes and average Votes Per Title (VPT) with custom number formatting.

// Dynamic KPI Labeling with Execution Variables
% Movie Votes Label = 
VAR percentoftotal = ROUND(DIVIDE([Movie Votes], [# Votes]), 2) * 100
VAR votespertitle = FORMAT(ROUND(DIVIDE([Movie Votes], [Movie Titles]), 0), "#,##")
RETURN "(" & percentoftotal & "%) | " & votespertitle & " VPT."

% Tv Votes Label = 
VAR percentoftotal = ROUND(DIVIDE([TV Votes], [# Votes]), 2) * 100
VAR votespertitle = FORMAT(ROUND(DIVIDE([TV Votes], [TV Titles]), 0), "#,##")
RETURN "(" & percentoftotal & "%) | " & votespertitle & " VPT."

Conditional Formatting & Dynamic Color Palette

Hex color scale generators based on SWITCH(TRUE()) logic to dynamically shade visual elements from neutral grey to signature Netflix red (#E50914) with accessible font contrast.

// Dynamic Conditional Formatting (10-Tier Palette Ramp)
Dynamic Rating Fill = 
SWITCH(
    TRUE(),
    [Avg Rating] >= 0 && [Avg Rating] < 1, "#EBEAEA",
    [Avg Rating] >= 1 && [Avg Rating] < 2, "#EAD1D2",
    [Avg Rating] >= 2 && [Avg Rating] < 3, "#EAB8BA",
    [Avg Rating] >= 3 && [Avg Rating] < 4, "#E99FA3",
    [Avg Rating] >= 4 && [Avg Rating] < 5, "#E8868B",
    [Avg Rating] >= 5 && [Avg Rating] < 6, "#E86D73",
    [Avg Rating] >= 6 && [Avg Rating] < 7, "#E7545B",
    [Avg Rating] >= 7 && [Avg Rating] < 8, "#E63B44",
    [Avg Rating] >= 8 && [Avg Rating] < 9, "#E6222C",
    [Avg Rating] >= 9 && [Avg Rating] <= 10, "#E50914"
)

Dynamic Rating Font = 
SWITCH(
    TRUE(),
    [Avg Rating] >= 0 && [Avg Rating] < 6, "#000000",
    [Avg Rating] >= 6 && [Avg Rating] <= 10, "#FFFFFF"
)
